\chapter*{Abstract}
This thesis presents DocQuery, a source-aware Retrieval-Augmented Generation (RAG) system for interactive querying of multiple uploaded documents. The system integrates multi-format ingestion, adaptive chunking, embedding-based retrieval, hybrid reranking, citation grounding, and runtime benchmarking.

\chapter{Introduction}
\section{Problem Statement}
Document QA systems often provide generic answers with weak traceability, especially when multiple files are uploaded together.

\section{Objectives}
\begin{itemize}
  \item Build a multi-document query assistant with citations.
  \item Improve retrieval quality using hybrid semantic+lexical reranking.
  \item Provide benchmarkable quality metrics and visual reports.
\end{itemize}

\chapter{System Architecture}
\section{Pipeline}
Upload $\rightarrow$ parse $\rightarrow$ chunk $\rightarrow$ embed $\rightarrow$ FAISS retrieval $\rightarrow$ hybrid rerank $\rightarrow$ LLM answer $\rightarrow$ citations + metrics.
