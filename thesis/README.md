# Thesis Template Usage

1. Edit `main.tex` and replace placeholders with your institute-required formatting.
2. Add generated figures from evaluation pipeline:
   - `backend/evaluation/results/plots/retrieval_answer_metrics.png`
   - `backend/evaluation/results/plots/judge_metrics.png`
3. Compile:
   ```bash
   cd thesis
   pdflatex main.tex
   ```
4. If your institute provides a custom class/template, copy your class file and adapt this content.
